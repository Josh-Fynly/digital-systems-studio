# Digital Systems Studio

Apple-inspired digital service hub for:

- Coding assistance
- CV redesign
- Website development
- Small business digital transformation

## Philosophy

Simple. Clean. Functional. High trust.

## Features

- Minimal Apple-style UI
- Smooth animations
- WhatsApp direct conversion
- Mobile-first design
- Fast loading

## Tech Stack

- React + Vite
- TailwindCSS
- Framer Motion

## Run Locally

```bash
npm install
npm run dev
````

## Build

```bash
npm run build
```

## Deploy

Deploy using Vercel and share link via WhatsApp, LinkedIn, and X.
